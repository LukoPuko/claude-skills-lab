→ The case for skills

What's a skill / why this matters

Skills are the difference between Claude as a generic assistant and Claude as a specialist. They are tiny, composable knowledge bundles that make your agent dramatically smarter at specific tasks — without you needing to retype the same instructions every session.

[01]

Knowledge bundles, on demand

A skill is a folder with a SKILL.md file plus optional scripts. When Claude detects a relevant task, it loads only the skills it needs — saving tokens and keeping behavior tight. Think dependency injection for an agent's brain.

[02]

One source of truth, every project

Install once globally with -g and every Claude Code session can use them. Or scope to a single repo. Skills travel with the code, not your head.

[03]

Built for the long tail

Generic chat is great for generic tasks. But shipping production code means knowing the 10,000 specific gotchas of React 19, Cloudflare D1, or Stripe Connect. Skills encode that expertise so you don't have to.

What we accept
  • Skills with a public source (GitHub repo, documented marketplace listing, or official Anthropic skill).
  • A working install command — either npx skills add, a built-in /command, or a clear git clone step.
  • A 1–2 sentence description that says what the skill does, not what category it's in.
  • An honest rating (1-5). Self-promotion is fine; lying about quality is not.
